## ⭐ Featured Project — Abu Qamar Workforce & Payroll System

A full-stack system for a supermarket's staff, attendance and payroll — **live and used daily by 10–30 employees**.

- **Stack:** TypeScript monorepo · Next.js / React · NestJS REST API (Swagger) · PostgreSQL · Docker · Render
- **Features:** attendance with breaks, schedules, leaves & overtime · payroll engine (salaries, payments, advances, debts) · PDF & Excel reports
- **Security & reliability:** roles & permissions · two-factor login · Argon2 hashing · rate limiting · full audit log · offline mode with sync · encrypted backups
- **UX:** Arabic RTL, mobile-first, light/dark mode, installable PWA

👉 [abu-qamar-workforce](https://github.com/mohamed-alamoudi/abu-qamar-workforce)
